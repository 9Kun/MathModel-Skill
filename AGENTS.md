# Codex project rules for this mathematical-modeling contest repository

- Treat this repository as a contest project, not as the MathModel-Skill development repository.
- Use `$paper-workflow-orchestrator` as the entry point for complete modeling-paper work.
- Run preflight and workflow status before downstream work, then follow the recommended next action.
- Official statements and attachments belong under `problem_files/`.
- All contest-specific code, cleaned data, figures, model results, drafts, QA records, and final deliverables belong under `paper_output/`.
- Do not write contest-specific code or results into `.agents/skills/`.
- Never invent model results, citations, data sources, successful executions, or validation passes.
- Do not enter formal writing before the official evidence gate passes.
- For interrupted work, resume from current workflow status instead of restarting completed stages.
- Preserve reproducibility: keep executable scripts, machine-readable result contracts, run manifests, and traceable numeric claims.
